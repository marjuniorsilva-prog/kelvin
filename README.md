# ClimaAqui
Site responsivo de previsão do tempo com localização, busca por cidade, previsão hora a hora, previsão de 10 dias, chuva, vento, rajadas, UV e alertas automáticos.

## Teste local
Sirva a pasta por HTTP/HTTPS. Exemplo:
python -m http.server 8080

Abra http://localhost:8080

## Dados
Protótipo integrado ao Open-Meteo. Antes de uso comercial/monetização, valide a licença/plano adequado da fonte meteorológica ou use backend/API própria.
